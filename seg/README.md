# 矩阵键盘输入数字 → 数码管显示

清翔 QX-MCS51 V3.5 / STC89C52RC。按矩阵键盘，数字像计算器一样从右侧移入 8 位数码管。

## 接线

| 模块 | 端口 | 说明 |
|------|------|------|
| 8 位数码管 | **P0** + **P2.6/P2.7** | 板载固定。P0=数据总线；P2.6=段选锁存；P2.7=位选锁存 |
| 4×4 矩阵键盘 | **P3** (P3.0~P3.7) | 杜邦线连接：行 P3.0~P3.3，列 P3.4~P3.7 |

数码管为**共阴极**，2 片 74HC573 分时锁存段码与位码。

## 操作

- 键号 **0~9**：输入对应数字（已显示的整体左移一位，新数字进最右）
- 键号 **10~15**：清屏归零
- 键号 = 行×4 + 列；按一下就能看出和丝印 S6~S21 的对应关系

## 显示原理（动态扫描）

8 位数码管段码共用 P0，无法同时点亮。靠**逐位快速轮流点亮**（每位约 1ms，整体 ~125Hz），人眼看上去 8 位同时亮。每位刷新顺序：

1. `P0=0x00` 锁段选 → 消隐（防止上一位的"鬼影"）
2. `P0=~(1<<i)` 锁位选 → 选中第 i 位（共阴，低电平选中）
3. `P0=段码` 锁段选 → 点亮该位的对应段

按键扫描期间也持续调用 `show_once()` 刷新，所以按键时屏幕不会灭。

## 调试提示

- **数字左右颠倒**：说明位选 `disp[]` 与物理位次序相反，把 `show_once` 里 `~(1<<i)` 改成 `~(1<<(7-i))` 即可。
- **缺笔画/段不对**：多为共阴/共阳搞反，本板是共阴；段码表 `SEG[]` 按 `dp g f e d c b a` 排列。
- **有重影**：加大消隐或缩短每位点亮时间。
