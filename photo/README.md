# 光控流水灯（无光闪烁 / 有光熄灭）

清翔 QX-MCS51 V3.5 / STC89C52RC。读 ADDA 模块的光敏电阻：**暗**时 P1 流水灯流动，**亮**时全灭。

## 接线

| 模块 | 端口 | 说明 |
|------|------|------|
| 流水灯 8×LED | **P1** | 板载固定，低电平点亮 |
| PCF8591 (ADC) | **P2.1=SCL, P2.0=SDA** | 软件模拟 I²C，地址 0x90/0x91 |
| 光敏电阻 | PCF8591 **AIN1** | 在 ADDA 模块上把光敏对应跳线接好 |

> P1（LED）与 P2.0/P2.1（I²C）互不冲突，可同时工作。

## 原理

1. 软件模拟 I²C 时序读 PCF8591 的 AIN1 通道，得到 0~255 的光照值。
2. 与阈值 `THRESHOLD` 比较判断明暗。
3. 暗 → 每隔 120ms 把亮点右移一位（流水灯）；亮 → `P1=0xFF` 全灭。

PCF8591 读数有"延迟一拍"特性，所以先读一次丢弃、再读有效值。

## 实物微调（都在 main.c 顶部宏）

| 现象 | 改法 |
|------|------|
| 明暗反了（**有光反而闪、遮住反而灭**） | `DARK_IS_HIGH` 改成 `0`（或 `1`） |
| 一直闪 / 一直灭，不随光变 | 调 `THRESHOLD`（0~255），取室内亮和遮挡时读数的中间值 |
| 完全无反应（读数恒定 0 或 255） | I²C 没通：把 `SCL/SDA` 的 P2.1/P2.0 对调；确认 ADDA 模块光敏跳线接好 |
| 灯亮/灭逻辑对但通道不对 | `LIGHT_CH` 换 `0x00`/`0x02`/`0x03` 试别的 AIN |

> 想知道实际读数，可以临时把光照值显示到数码管（参考 `../seg`），方便定阈值——需要的话我帮你加一版带数码管读数的调试程序。
